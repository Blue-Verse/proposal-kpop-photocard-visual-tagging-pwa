핵심 요구사항 분석

  • 비주얼 태깅 에디터 (판매자) — 이미지 캔버스 위 터치/클릭 좌표 기반 태그(핀) 생성, 드래그앤드롭 이동·삭제, 태그별 가격·라벨·상태·스타일 입력
  • 탐색·구매 인터랙션 (구매자) — 게시글 리스트·상세 이미지 뷰어, 태그 탭 시 상세 팝업, 다중 태그 선택 시 하단 바 실시간 금액 합산, 선택 데이터를 파라미터로 채팅방 진입
  • 채팅·거래 상태 관리 — Sendbird 등 검증된 SDK 기반 1:1 실시간 채팅, 거래 상태 토글(판매중·협의중·판매완료), Sold Out 시각 비활성화, 상태 변경 시 시스템 메시지 자동 발송
  • 회원·계정 — 소셜 로그인(카카오·네이버·구글), 판매자/구매자 프로필·모드 전환, 마이페이지(판매글·찜·거래 상태별 목록)
  • PWA·알림 — PWA 표준 규격 준수(홈 화면 추가), 브라우저 푸시 알림 권한 획득 및 채팅/상태 변경 알림 발송
  • 성능 — 모바일 환경에서 태그 드래그앤드롭 시 끊김 없는 부드러운 인터랙션 보장

제안 포인트

1. 좌표 기반 이미지 인터랙션 직접 구현 경험. 본 프로젝트의 핵심이자 우대 요건인 "이미지 위 좌표 기반 인터랙션(드래그·핀·에디터)"은 캔버스 게임 엔진(Phaser.js) 기반 인터랙티브 플랫폼을 직접 구축한 경험과 직결됩니다. 좌표계 변환, 히트 영역 판정, 드래그 핸들링, 반응형 캔버스 리사이징 등 태깅 에디터의 난점을 사전에 검증된 패턴으로 안정적으로 풀어냅니다.

2. 검증된 채팅 SDK 활용으로 리스크 최소화. 공고 권장사항대로 채팅은 직접 구현이 아닌 Sendbird SDK를 활용합니다. 1:1 채팅방 생성, 메시지 동기화, 시스템 메시지 자동 발송, 거래 상태 연동을 SDK의 검증된 인프라 위에서 구현하여 안정성과 일정을 모두 확보합니다.

3. PWA·소셜 로그인·푸시 통합 경험. 모바일 우선 소셜 앱에서 소셜 로그인, 멀티 알림(7종), 실시간 동기화를 구현한 경험을 바탕으로 PWA 설치형 경험과 브라우저 푸시 알림을 표준 규격에 맞게 구축합니다.

4. 산출물 완성도 1순위 대응. 클라이언트 제공 화면 기획서·Figma 원본을 충실히 반영하고, 명세 고도화 → 마일스톤 단위 검수 → 모바일 인터랙션 QA의 단계별 품질 게이트로 완성도를 최우선으로 관리합니다.

PRD (Product Requirements Document)

프로젝트 요구사항을 정의하고 기능 범위를 명확히 합니다.

1. 프로젝트 배경 및 목적

현재 포토카드 셀러들은 카카오 오픈채팅·트위터 이미지에 직접 글씨를 써서 거래하는 불편을 겪고 있습니다. 본 프로젝트는 이미지 위 좌표 기반 인터랙션(드래그·핀)을 도입하여 시각적이고 빠른 거래 매칭을 돕는 전용 C2C 플랫폼을 모바일 PWA로 런칭하는 것을 목표로 합니다. 디자인은 클라이언트가 Figma로 제공하며, 자체 결제 기능은 범위에서 제외됩니다.

2. 사용자 정의

사용자 유형설명주요 기능
판매자포토카드를 등록·판매하는 사용자이미지 업로드, 비주얼 태깅, 태그별 가격·상태 설정, 거래 상태 관리
구매자포토카드를 탐색·구매 문의하는 사용자게시글 탐색, 태그 탭 상세 확인, 다중 선택·금액 합산, 채팅 문의, 찜
공통(회원)모드 전환이 가능한 일반 회원소셜 로그인, 프로필·모드 전환, 마이페이지, 푸시 알림

3. 기능 요구사항

3.1 회원 및 계정 관리

  • [필수] 소셜 로그인(카카오·네이버·구글) 연동 및 회원가입 처리
  • [필수] 판매자/구매자 프로필 설정 및 모드 전환
  • [필수] 마이페이지 — 내 판매글, 찜 내역, 거래 상태별 목록
  • [필수] PWA 브라우저 푸시 알림 권한 획득 및 채팅/상태 변경 알림 발송

3.2 포토카드 등록 및 비주얼 태깅 (판매자)

  • [필수] 다중 이미지 그리드 업로드 및 모바일 최적화 리사이징
  • [필수] 이미지 캔버스 위 터치/클릭 좌표 기반 태그(핀) 생성
  • [필수] 태그 드래그앤드롭 이동 및 삭제 인터랙션
  • [필수] 태그별 가격·라벨·상태 입력 폼 및 태그 스타일(색상 등) 설정

3.3 탐색 및 구매 인터랙션 (구매자)

  • [필수] 게시글 리스트 뷰 및 상세 이미지 뷰어
  • [필수] 이미지 위 태그 탭 시 상세 정보 팝업 노출
  • [필수] 다중 태그 선택 시 하단 바에 실시간 총 예상 금액 합산
  • [필수] 선택한 포토카드 데이터를 파라미터로 전달하여 1:1 채팅방 진입

3.4 채팅 및 거래 상태 관리

  • [필수] Sendbird 등 외부 채팅 SDK/SaaS 연동을 통한 1:1 실시간 채팅
  • [필수] 거래 상태(판매중·협의중·판매완료) 토글 변경
  • [필수] 판매 완료 태그 시각적 비활성화(Sold Out) 및 이미지 업데이트
  • [필수] 거래 상태 변경 시 채팅방 내 시스템 안내 메시지 자동 발송

4. 비기능 요구사항

항목요구사항
성능/인터랙션모바일 환경에서 태그 드래그앤드롭 시 끊김 없는 부드러운 인터랙션 보장 (60fps 목표)

5. 기술 제약사항

프론트엔드/백엔드 기술 스택은 자유 제안이 가능하나, 본 제안은 좌표 기반 캔버스 인터랙션에 최적화된 react-konva와 PWA 지원이 강력한 Next.js를 채택합니다. 채팅은 직접 구현 대신 검증된 Sendbird SDK를 활용하여 안정성·일정 리스크를 최소화합니다. 상세 기획서는 NDA 체결 후 공유되는 점을 반영하여, 착수 직후 명세 고도화 단계를 배치합니다.

6. 범위 외 사항 (Out of Scope)

  • 자체 결제(PG) 시스템 — 공고상 명시적 제외
  • Figma 디자인 제작 — 클라이언트가 원본 제공
  • 네이티브 앱(iOS/Android) 스토어 배포 — 본 MVP는 PWA 기준
  • 상세 기획서 작성 — 클라이언트 화면 기획서 기반 명세 고도화로 한정
